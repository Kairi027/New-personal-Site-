# Kairi 的小站

一个深蓝夜色风格的个人博客，带开发者/访客两套身份、仓库式的项目页，以及点赞评论互动。
背景使用 `pics/Home.webp`，首页背景音乐使用 `music/Home BGM.m4a`。

## 打开方式

**双击 `index.html`** 即可（推荐 Chrome / Edge）。所有页面都用相对路径引用资源，不需要搭建服务器。

> 想让首页背景音乐**刷新后也免点击自动播放**，请用 `启动博客-自动播放.bat` 打开（原因见下面「登录与身份」）；在平时的浏览器窗口里，刷新之后按浏览器规则得点一下。

**在线版（任何人都能访问）**：<https://kairi027.github.io/New-personal-Site-/> —— 由 GitHub Pages 从 `gh-pages` 分支发布，本地改完推一次 `git push origin main:gh-pages` 就更新（`main` 是开发分支）。在线时是纯静态浏览：写文章、上传项目文件、点赞评论仍然需要本机服务。

> 在线版想让背景音乐**刷新后也免点击**，点右下角提示里的「下载在线版启动器」（`启动博客-自动播放-在线版.bat`）：它用带 `--autoplay-policy=no-user-gesture-required` 的独立浏览器配置打开线上地址，第一次登录一次之后，打开和刷新都自动出声。网页自己不能调用本地 bat，这是浏览器对"自动出声"的硬限制，任何站点都绕不过。

另外附带一个**本地服务**（`tools/blog-server.py`，只监听 `127.0.0.1:8765`），它负责三件事：
写项目文件、读项目文件（打包下载时读取图片等二进制）、保存点赞评论与回复。
**浏览不需要它，写东西才需要。** 服务没启动时，浏览、看代码、下载源码都正常，只是不能保存、评论只存在本机。

## 登录与身份

站点最前面是 `login.html`；**首页是就地登录**——没登录时直接打开 `index.html`，登录卡片会盖在首页上（不跳页），这样"点进入"的那一下就能顺势把背景音乐带声播起来：

| 身份 | 怎么进 | 能做什么 |
| --- | --- | --- |
| 开发者 | 账号 `kairi001176` / 密码 `wtjzxh1979` | 新建 / 编辑 / 删除文章与项目、上传项目文件、回复评论 |
| 访客 | 一键进入，不需要密码 | 看文章、点赞、评论；看项目简介、看源码仓库、打包下载 |

- 登录状态记在本浏览器里，直到点右上角徽章 →「退出登录」。除首页和登录页外，任何页面没有会话都会自动跳到登录页。
- 首页音乐只有一个控制：导航栏右上角的「音乐」按钮（点一下播放 / 再点一下暂停，播放中图标会转）。**登录卡片期间固定不播**，点「进入」成功那一刻和开场渐变特效一起开始播。
- **为什么"登录后会响、刷新后不响"**：浏览器只允许"当前这个文档被用户点过"之后出声。登录是就地登录，点「进入」那一下正好把声音权限给了当前文档；刷新（F5）会换成一个**全新的文档**，点击记录清零，于是 `play()` 直接被拒（实测 Chrome 154 抛 `NotAllowedError`，把音量设成 0 再淡入也照样被拒）。这是浏览器硬规则，页面脚本绕不过去——`js/bgm.js` 能做的是"能放就立刻放，不能放就等你点第一下"。
- 所以刷新之后按你用什么打开，分两种情况：
  - **`启动博客-自动播放.bat`（或桌面快捷方式）**：它给浏览器加了 `--autoplay-policy=no-user-gesture-required`，打开和刷新都会**直接响起，一下都不用点**。实测 Chrome 154：本目录 `index.html` 的 `file://` 地址与 `http://127.0.0.1:8765/` 都有效。默认打开的就是本目录的 `index.html`，用的是给博客单独准备的浏览器配置 `%LOCALAPPDATA%\KairiBlog`（不动你平时用的浏览器；第一次需要在那个窗口里登录一次，之后一直自动播放）。加 `--http` 参数可改成打开本地服务地址。
  - **平时的浏览器**：右下角会出现可点的 `♪` 提示，**点页面任意处**（或点提示本身）音乐立刻响起，不用去找导航栏那个按钮；提示里也写明了上面那条出路。
- 想让平时的浏览器也免点击：给本站开一次声音权限（Chrome：地址栏左侧图标 → 网站设置 → 声音 → 允许）。这**只对 `http://127.0.0.1:8765/` 有效**——`file://` 页面在 Chrome 里没有「声音」这一栏，也不参与它的媒体参与度（MEI）评分，所以双击 `index.html` 打开的窗口只能靠点一下。
- 「暂停」只记在当前标签页：这次点了暂停就一直暂停，重新打开本站仍会自动播放。
- 万一浏览器在播放中途把音乐掐掉（静音自动播放的老问题），`js/bgm.js` 会在几秒内自查一次并自动接回来；接不回来就重新亮出提示。控制台里 `KairiBgm.state()` 看状态、`KairiBgm.retry()` 手动再试。
- 导航右侧常驻身份徽章：开发者是粉色「开发者模式」，访客是灰色「访客」；点徽章可以改密码或退出。
- 访客看不到任何新建 / 编辑 / 删除 / 上传 / 回复入口（工具栏在 HTML 里就是 `hidden`）。
- 密码只以哈希形式存在本机（优先 SHA-256）。**这是前端门面，不是安全边界**——查看源码就能绕过。

## 项目（仓库式）

`projects.html` 是卡片列表，点进去是 `project.html?p=<项目id>`，内容就是**项目介绍 + 源代码仓库**，没有"在线体验"：

- **介绍**：简介、技术栈、亮点、截图。
- **仓库**：文件树 + 代码查看器（文本内容内联在 `projects-data.js` 里，服务没启动也能看；没内联的文件在服务启动时实时读取）+ **打包下载 ZIP**（文本直接打包，图片等二进制通过服务读取；生成的是 Windows 能直接解压的标准 zip）。
- 内置项目：**云阙飞戈**（`projects/cloudspire/`，46 个文件，来自它的 `src/`）与**视频原画提取**（`projects/crawler/`，13 个文件）。它们可以改介绍、可以补文件，但不能删除。

### 开发者：新建 / 编辑项目

在「项目」页点 **新建项目** 进入 `project-edit.html`：

1. **不需要选任何文件夹**（本地服务直接写进 `个人博客\projects\<项目id>\`）。
2. 用「选择文件 / 选择文件夹」或拖拽上传；选文件夹会保留目录结构。
   上传时会**自动跳过** `.venv`、`venv`、`env`、`node_modules`、`.git`、`__pycache__`、`.idea`、`.vscode`、`dist`、`build`、`target`、`.next`、`.cache` 等依赖/缓存目录，并告诉你跳过了多少个。
3. 传完自动解析出技术栈、语言分布、截图、简介草稿、亮点；点「应用解析结果」填进表单，之后可以改。
4. 点「保存项目」：文件落盘 → **自动截图生成预览图** → 写 `projects/projects-data.js`。

### 运行方式与自动预览图

保存项目时会自动生成封面。**关键在于这个项目怎么才能"跑起来"**，所以编辑页里有一组「运行方式」：

| 情况 | 怎么填 | 截图怎么来的 |
| --- | --- | --- |
| 纯静态页面（有 index.html，不依赖服务器） | 三栏都留空 | 直接打开 `projects/<id>/index.html` 截图 |
| 需要起服务 / 构建（Vite、Python 服务、Streamlit…） | 填**启动命令** + **预览地址**（必要时填**工作目录**） | 在项目目录里把项目跑起来 → 轮询等地址可用 → 截运行中的程序 → 杀掉进程 |
| 桌面程序（pygame、tkinter、打包好的 exe…） | 只填**启动命令**（**预览地址留空**，必要时填**工作目录**） | 把程序跑起来 → 等它自己的窗口出现 → 抓那个窗口当封面 → 连同子进程一起杀掉 |

编辑页会从仓库文件里认一遍"这个项目怎么跑"，并把候选列出来（Python 桌面程序 → 打包 exe → Streamlit / Python 服务 / `package.json` 的 `scripts.dev` / `start.bat`、`*.ps1` → 纯静态 `index.html`）：**上传完会自动填上认出来的第一个**，也可以点别的候选改，或者自己手写。工作目录会顺着脚本里引用的资源路径自动推出来（例如 `东方复刻/main.py` 里写的是 `img/`、`bgm/`，那工作目录就该是项目根目录）。

细节：

- 服务用**独立临时用户目录**跑隐藏的 headless Chrome，不会影响你正在用的浏览器。
- 运行起来的应用（Streamlit、Vite 这类）内容是异步渲染的，所以会**隔几秒连截几张、挑内容最丰富的一张**，避免截到加载骨架屏。
- 桌面程序（有启动命令、没有预览地址）会在保存前**弹一个确认框**，你同意后它才会真的在你电脑上跑起来、抓窗口；跑的时候窗口会短暂出现在桌面上，可能还会出声。
- 抓窗口优先用 Pillow（装了就用），没装也能跑：改用 Windows GDI 抓像素 + 标准库 zlib 自己写 PNG。
- 截图结束后会连同子进程一起杀掉（`taskkill /T`），不会留下后台服务。
- 启动命令的输出写到 `data/launch-<项目id>.log`，截图失败时可以看它。
- 兜底：没配运行方式又没有 `index.html`、没装浏览器、或截图失败时，会退回"仓库里第一张图片 → 首字母占位图"，并把原因说清楚。

> **注意**：启动命令是会被真的执行的（在你项目目录里、以你的身份）。这是本机单人工具，别把服务暴露出去被人乱调用。

## 文章

- 开发者在 `articles.html` 新建 / 编辑 / 删除；访客只读，但可以**点赞**和**评论**，开发者还能**回复**评论（作者固定显示「站长」，由服务端写死）。
- 正文支持少量 Markdown：`# 标题`、`**加粗**`、`*斜体*`、反引号行内代码、三反引号代码块、`- 列表`、`1. 有序列表`、`> 引用`、`[链接](url)`、`---` 分隔线。
- 文章存在 `js/articles-data.js`（由本地服务写入，随文件夹传播）。文件为空时会退回 `js/posts.js` 的默认文章或浏览器 localStorage，并择机写回文件。
- 备份按钮：`导出 JSON`、`导入 JSON`、`复制为 posts.js`、`恢复默认文章`（都不影响已有文章）。

## 点赞与评论

- 数据存在 `data/social.json`，并由服务同步生成 `js/social-data.js`（`file://` 页面只能靠 `<script src>` 读它）。
- 服务在跑：赞和评论会保存进博客，别人打开也看得到。服务没跑：只存在本机浏览器，界面上会明确标注「仅本机」。
- 访客的点赞以浏览器为粒度（同一浏览器可取消），不做账号体系；评论昵称由访客自己填。

## 本地服务

```
启动博客服务.bat        手动启动（带命令行窗口，关掉即停止）
后台启动博客服务.vbs    静默启动（开机自启调用的就是它，也可以直接双击）
安装开机自启.vbs        在「启动」文件夹放一个快捷键，并立刻启动一次
卸载开机自启.vbs        取消自启，并可选停止正在运行的服务
启动博客-自动播放.bat   用独立配置 + 允许自动播放打开小站：打开 / 刷新都零点击放背景音乐
```

服务接口（都带 CORS，含 `Access-Control-Allow-Private-Network`）：

| 接口 | 作用 |
| --- | --- |
| `GET /api/ping` | 探活 |
| `PUT` / `DELETE` / `GET /api/file/<项目id>/<路径>` | 写 / 删 / 读项目文件 |
| `DELETE /api/project/<项目id>` | 递归删除项目目录 |
| `POST /api/data/projects`、`POST /api/data/articles` | 写入数据文件 |
| `GET /api/social`；`POST /api/social/like`、`/comment`、`/reply`、`/delete-comment` | 互动 |
| `POST /api/screenshot` | 生成封面。`mode` 三选一：`web`（起服务后截那个地址）/ `static`（直接开页面）/ `desktop`（跑起来抓程序窗口）；不传 `mode` 就按老规则推断（有 `url` 当 web，只有 `command` 当 desktop）。参数：`projectId` / `name` / `mode` / `entry` / `command` / `cwd` / `url` / `waitMs` / `settleMs` |

> 服务只监听 `127.0.0.1`、不加鉴权，属于本机工具，**不要暴露到局域网或公网**。
> 万一 `file://` 下连不上服务，它也能把整个博客当静态站点托管：浏览器打开 `http://127.0.0.1:8765/` 即可。

## 已知限制

- 文章、项目数据、互动数据都是**本机文件**，`file://` 与 `http://` 是两套独立的浏览器存储（登录状态在 localStorage；音乐"暂停"只记在当前标签页）。
- 访客的点赞以浏览器为粒度；评论昵称可随意填写，没有账号体系。
- 上传不做体积上限，但文本内联有 2MB 预算（只影响浏览速度，不影响磁盘上的完整文件）。
- `file://` 下跨文件 `fetch` 与 ES Module 会被浏览器拦截，本项目刻意避开了这两者。
- 在线版（GitHub Pages）是纯静态托管：只有浏览可用，写文章 / 上传 / 点赞评论会降级为只读；免点击自动播放依赖 `启动博客-自动播放*.bat` 这类带参数的启动器，网页无法代劳。
