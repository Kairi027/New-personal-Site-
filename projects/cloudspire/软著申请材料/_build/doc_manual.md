软件名称：云阙飞戈（Lances of Cloudspire）小游戏软件
软件版本：V1.0
文档类型：用户操作手册（文档鉴别材料）
编写日期：2026年9月
运行平台：微信小游戏平台（Android / iOS 微信客户端）

# 1 引言

## 1.1 编写目的

本手册面向软件著作权登记、游戏玩家以及后续维护人员编写，用于说明「云阙飞戈（Lances of Cloudspire）小游戏软件 V1.0」（以下简称“本软件”）的运行环境、安装与启动方法、界面与操作方式、各功能场景的使用方法、玩法系统、关卡与难度配置、数据存储规则、软件结构与技术特点等内容，帮助用户快速上手并正确使用本软件。

本软件是一款运行于微信小游戏平台的原生竖版弹幕射击类空战游戏，使用 JavaScript 语言基于 Canvas 2D 图形接口开发，采用复古科幻空战题材，支持单机闯关、难度挑战、成就收集与多人对战（PK）等玩法。

## 1.2 软件简介

本软件以“云阙飞戈中队对抗异星侵蚀机群、保卫天穹”为故事背景。玩家扮演“云阙飞戈”中队最后的王牌飞行员，驾驶飞戈-1 截击机，在黄土天穹、雷暴云海、天穹王座与堙灭虚空等场景中迎战成群侵蚀机、陨石、UFO、异形母舰与各具特色的 BOSS，通过躲避弹幕、击落敌机、拾取掉落、积累经验升级，最终守护天穹。

软件采用单指触控拖动的方式控制战机移动，自机会自动开火，操作门槛低、节奏爽快；同时提供 Easy、Normal、Hard、Insane 四档难度，内置 4 个风格各异的关卡与多场 BOSS 战、双结局剧情、成就系统、本地存档与实名认证流程，并支持基于 WebSocket 的本地/局域网多人对战模式，兼顾休闲玩家与硬核弹幕玩家。

## 1.3 文档约定

本手册中，“自机”指玩家控制的战机，“敌机”指敌方单位，“BOSS”指关卡首领，“必杀”指可主动释放的全屏攻击技能，“PK 模式”指玩家之间的对战模式。菜单按钮名称以游戏画面实际显示为准。文中涉及的按键与触控操作均针对移动端触摸屏；在微信开发者工具模拟器中可使用鼠标模拟触控。

# 2 软件运行环境

## 2.1 硬件环境

本软件面向移动终端运行，建议运行硬件环境如下：支持微信客户端的 Android 智能手机（建议 Android 8.0 及以上、运行内存 3GB 及以上）或 iPhone（建议 iOS 12.0 及以上、运行内存 3GB 及以上），屏幕分辨率不低于 1280×720；开发调试阶段亦可运行于桌面计算机的微信开发者工具模拟器环境中，桌面计算机建议配置为 Intel Core i3 及以上处理器、4GB 及以上内存、分辨率 1920×1080 的显示器。

## 2.2 软件环境与支撑平台

运行平台为微信小游戏平台，即 Android/iOS 版微信客户端内置的小游戏运行环境，软件以竖屏方式呈现；开发与调试依托微信开发者工具（选择“小游戏”工程类型）。软件的本地数据（实名信息、存档、成就、设置）通过微信小游戏本地缓存 Storage 持久化；多人对战模式通过 WebSocket 与对战服务器通信，开发期可使用本地服务器与内网穿透服务进行联机调试。游戏画面渲染依赖 Canvas 2D 接口，字体、图片、音频等资源由小游戏运行环境提供加载能力。

# 3 安装与启动

## 3.1 使用微信开发者工具导入运行

第一步：在电脑上安装最新版微信开发者工具，并使用微信扫码登录。
第二步：启动微信开发者工具，选择“小游戏”项目类型，点击“导入项目”，选择本软件工程目录。
第三步：在导入设置中填写或选择 AppID（可使用测试号，或在 project.config.json 中配置正式 AppID），点击“确定”完成导入。
第四步：工具自动编译后，可在模拟器中看到游戏加载画面，点击“编译”可重新编译运行；点击“预览”可生成二维码，使用手机微信扫码即可在真机中体验。

## 3.2 真机预览与发布

真机预览：在微信开发者工具中点击“预览”，手机微信扫描二维码后进入小游戏；真机环境与模拟器环境在触控、音频、存储等接口上保持一致。
上传发布：在工具中点击“上传”，填写版本号与项目备注后上传代码，随后在微信公众平台（小游戏后台）提交审核并发布。发布前请确认 project.config.json 中的 AppID 为正式 AppID，并完成小游戏类目、用户隐私保护指引等平台配置。

## 3.3 浏览器本地调试（可选）

为便于开发期调试，工程提供了浏览器预览适配层：在 Node.js 环境中依次运行构建脚本与本地服务器脚本，然后在浏览器中打开本地地址即可进行调试。浏览器预览仅用于本地开发调试，不参与微信小游戏打包发布。

# 4 游戏操作说明

## 4.1 基本操作

- 移动：在屏幕任意位置按住并拖动，自机跟随手指移动；松开手指，自机停止移动。
- 攻击：自机进入关卡后自动开火，无需手动点击攻击按钮。
- 必杀技：点击屏幕左下角的红色能量球，释放“全域清扫”清屏必杀，清除场上敌方弹幕并对敌机造成大范围伤害。
- 暂停：点击屏幕右上角的暂停按钮，进入暂停界面。
- 菜单选择：在标题、难度、成就等菜单界面中，直接点击对应按钮完成选择。
- 文本输入：在实名认证、昵称输入等界面，点击输入框后通过系统键盘输入文字。

## 4.2 界面布局

- 竖屏战斗界面自上而下依次为：顶部信息栏（分数、生命、经验与等级、Boss 血条等）、战斗区域、自机与敌机/弹幕层、底部操作区（左下必杀能量球、右上暂停按钮）。
- 标题界面：中央为游戏 Logo 与标题，下方依次排列“开始游戏/继续游戏”“挑战模式”“成就”“多人对战”“退出”等功能按钮。
- 所有界面均采用 720×1280 的逻辑分辨率进行适配，在不同屏幕尺寸下按比例缩放居中显示，四周以深色星空背景填充。

# 5 游戏场景与功能说明

## 5.1 实名认证场景

首次进入游戏时展示实名认证界面，用于完成防沉迷实名登记。界面提供“姓名”与“身份证号”两个输入框以及“提交”按钮。软件在本地对身份证号进行格式与校验位校验（18 位、出生日期、校验码等），校验通过后保存认证状态并进入标题界面；校验失败时给出错误提示并可重新输入。已完成认证的设备再次进入时会自动跳过本场景。

## 5.2 加载场景

软件启动后先进入加载场景，负责加载图片、音频等资源并初始化游戏上下文；加载完成后自动跳转到实名认证或标题场景。加载场景同时用于音效系统解锁等初始化工作。

## 5.3 标题场景

标题场景是游戏的主菜单，包含以下功能：开始新游戏（进入难度选择）、继续游戏（读取本地存档直接进入上次进度）、挑战模式、成就查看、多人对战入口、退出确认、联系信息与开发者调试入口。标题背景带有动态星空、山峦与飘浮粒子效果，并循环播放标题音乐。

## 5.4 难度选择场景

玩家在开始新游戏时可选择难度：Easy（第 1 关）、Normal（第 1~2 关）、Hard（第 1~3 关）与 Insane（第 1~4 关，含隐藏要素）。不同难度影响敌机生命、敌机速度、子弹速度、敌机数量、刷新间隔与 BOSS 强度等参数。选择后进入对应关卡的剧情场景。

## 5.5 剧情场景

在进入每个关卡前展示剧情文本，以打字机方式逐段显示故事内容，交代关卡背景与敌方情报。玩家可点击屏幕跳过或加速剧情，剧情结束后自动进入关卡战斗。

## 5.6 关卡战斗场景

核心玩法场景。玩家通过触控拖动控制自机在屏幕下半区移动，自机自动发射子弹攻击敌人；敌人从屏幕上方以多种编队、路径与弹幕方式入场。玩家需要击落敌机、躲避弹幕、拾取掉落物并击败关卡 BOSS 才能通关。战斗过程中实时显示分数、生命、经验、等级、能量与 BOSS 血条等信息，并提供暂停、结束等控制。

## 5.7 暂停场景

战斗过程中点击暂停按钮进入暂停界面，可执行以下操作：继续游戏、重新开始本关、存档并退出到标题、不存档退出到标题。暂停时游戏循环挂起，恢复后继续。

## 5.8 游戏结束场景

当自机生命耗尽时进入游戏结束界面，显示本局得分、到达关卡与难度等信息，并提供“重新挑战”“返回标题”等按钮；玩家可读取最近存档或重新开始。

## 5.9 关卡结算场景

通关当前关卡后进入结算界面，显示通关关卡、累计得分与获得奖励；若当前难度仍有后续关卡，可选择进入下一关剧情；若已通关当前难度的全部关卡，则进入对应结局。

## 5.10 结局场景

游戏根据难度与通关进度提供多结局演出：在 Hard 及以上难度通关第 3 关后进入“假结局（结局 A）”；在 Insane 难度完成全部关卡后进入“真结局（结局 B）”。结局场景以剧情文本与画面演出收束故事，演出结束后可返回标题。

## 5.11 成就场景

成就界面展示全部成就条目及其解锁状态：PVP 达人（在 PK 模式取得一次胜利）、虚假的晴空（首次通关 Hard 模式、达成结局 A）、星海烬余安（首次通关 Insane 模式、达成结局 B）、Hello,World（解锁内测跳关模式）。达成条件后自动点亮，成就数据本地持久化。

## 5.12 广告场景与跳关解锁

游戏内设有广告场景（云阙商城·星海补给站等展示页），用于内测跳关功能的解锁流程：玩家观看广告后可解锁标题界面的调试跳关入口，便于测试后续关卡。广告场景带有计时与完成回调逻辑，可在不接入真实广告 SDK 的情况下以演示内容完成流程闭环。

## 5.13 多人对战场景

多人对战（PK）模式包含昵称输入场景与房间场景：玩家先输入昵称，再创建房间或输入房间码加入房间，双方通过 WebSocket 服务器建立连接并进行对战。系统负责房间编号、玩家序号、昵称同步、随机种子同步、时钟校准、延迟统计与对战消息（开始、状态、认输等）的收发。对战结束后依据胜负结果解锁相应成就。
# 6 玩法系统设计

## 6.1 自机（玩家战机）

自机为“飞戈-1”截击机，位于屏幕下方，跟随手指移动。自机持续自动开火，子弹命中敌人后造成伤害；自机被敌方子弹或敌机本体击中会损失生命，生命耗尽则游戏结束。自机通过击落敌机获得经验，经验满足后升级，升级可提升火力或恢复状态，并通过 HUD 显示等级与经验进度。

## 6.2 敌机与 BOSS 体系

- 小型侵蚀机：低血量、高速俯冲，常见于编队与批次攻击。
- 中型侵蚀机：具备扇形弹幕攻击能力，血量与得分中等。
- 重型侵蚀机：血量较高，可释放扩散弹幕，是关卡中的精英单位。
- 狙击侵蚀机：远距离瞄准射击，弹道指向性较强。
- 突袭侵蚀机：快速突进型单位，需要优先处理。
- 护盾侵蚀机：带有护盾，可抵挡一定伤害，护盾存在时具有特殊表现。
- 大型侵蚀机与大型 UFO：高血量大型单位，常作为关中小首领出现。
- 陨石（小/中/大）：不可攻击或高血量障碍型目标，以滚动、坠落等轨迹进入战场。
- 异形母舰：具备多阶段攻击的强力单位。
- 关卡 BOSS：第 1 关 BOSS 为重型突击轰炸机，第 2 关 BOSS 为风暴巡洋舰，第 3 关由锋卫 α/β 双护卫与终焉神机组成，Extra 关 BOSS 为堙灭虚空之核。BOSS 拥有独立血条、多阶段技能、激光、散射弹幕与召唤小兵等攻击方式。

## 6.3 弹幕与子弹

游戏内子弹分为自机子弹与敌方子弹两类，均按对象池方式管理。敌方子弹提供多种弹道与弹幕样式，包括直线弹、扇形弹（3 向、5 向等）、扩散弹、环绕弹、激光与 BOSS 专属弹幕；不同敌机与 BOSS 按配置释放对应弹幕，构成不同密度的弹幕压力。子弹具备半径碰撞判定，与自机、敌机、护盾等对象进行碰撞检测。

## 6.4 掉落与成长

击落敌人后按概率掉落经验道具与回复道具：经验道具提供经验值，回复道具恢复自机生命。自机通过经验升级获得成长，等级提升会带来火力与生存能力的增强，并在界面中实时反馈。

## 6.5 必杀技（全域清扫）

自机左下角显示必杀能量球，能量积满后可点击释放“全域清扫”：清除场上敌方弹幕并对全屏敌人造成大量伤害，是危机时刻的保命与清场手段。能量通过攻击与击落敌机积攒。

## 6.6 计分与经验

击落不同敌人获得对应分数与经验，分数在顶部 HUD 实时累计并在结算界面展示；经验用于升级成长。分数与经验数值均在关卡配置中按敌人类型定义，便于数值平衡调整。

## 6.7 碰撞与伤害

自机、敌机、子弹、掉落物均以圆形碰撞体近似，按半径进行两两碰撞检测。自机与敌方子弹或敌机碰撞时受伤并进入短暂无敌；BOSS 与大型单位具备更高血量与伤害抗性。碰撞、伤害、无敌帧等参数集中在实体代码中统一管理。

# 7 关卡与难度配置

## 7.1 关卡列表

- 第 1 关：黄土天穹·钢铁机群，BOSS 为重型突击轰炸机。
- 第 2 关：雷暴云海·沉云遗迹，BOSS 为风暴巡洋舰。
- 第 3 关：天穹王座·终焉神域，BOSS 为锋卫 α/β 与终焉神机。
- Extra 关：堙灭虚空·宇宙坟场，BOSS 为堙灭虚空之核。

每个关卡由若干“波次/编队”脚本化生成，包含出场批次、敌机编队、路径、弹幕与 BOSS 战阶段；关卡配置文件按关卡 ID 组织，便于扩展新关卡。

## 7.2 难度参数

- Easy：关卡范围第 1 关；敌机生命 0.7 倍、敌机速度 1.0 倍、子弹速度 1.0 倍、BOSS 生命 1.0 倍、敌机数量 0.7 倍、刷新间隔 1.35 倍。
- Normal：关卡范围第 1~2 关；敌机生命 1.0 倍、敌机速度 1.25 倍、子弹速度 1.35 倍、BOSS 生命 1.35 倍、敌机数量 1.0 倍、刷新间隔 1.0 倍。
- Hard：关卡范围第 1~3 关；敌机生命 1.5 倍、敌机速度 1.45 倍、子弹速度 1.7 倍、BOSS 生命 1.75 倍、敌机数量 1.25 倍、刷新间隔 0.85 倍。
- Insane：关卡范围第 1~4 关（含隐藏内容）；敌机生命 2.0 倍、敌机速度 1.55 倍、子弹速度 1.9 倍、BOSS 生命 2.0 倍、敌机数量 1.5 倍、刷新间隔 0.75 倍。

# 8 数据存储与实名校验

## 8.1 本地存储

软件使用微信小游戏本地缓存持久化以下数据：存档数据（关卡、难度、分数、生命、等级、经验等，键名 cloudspire_save_v1）、实名认证数据（键名 cloudspire_auth_v1）、成就数据（键名 cloudspire_achievements_v1）与跳关解锁标记（键名 cloudspire_debug_unlocked_v1）。各存储数据结构均带版本号字段，便于后续升级迁移。

## 8.2 实名校验规则

实名认证在本地完成姓名与身份证号校验：身份证号须为 18 位，前 17 位为数字，末位可为数字或 X；软件校验出生日期合法性与末位校验码，校验通过后视为认证成功。该逻辑仅用于本地流程演示与防沉迷入口登记，实际商用发布时应按国家规定接入权威实名认证接口。

# 9 软件结构与模块

## 9.1 总体结构

本软件采用模块化设计：game.js 为小游戏入口；src/main.js 为游戏主类，负责初始化画布、输入、音频、场景管理器与主循环；src/core 提供平台适配、场景管理、输入、存储、音频、资源、粒子、成就与程序化背景等基础模块；src/utils 提供数学、随机数、身份证校验与着色等工具；src/config 提供难度与关卡配置；src/ui 提供菜单、HUD 与氛围特效绘制；src/entities 实现自机、子弹、敌机、BOSS 与异形母舰等实体；src/scenes 实现实名、标题、难度、剧情、关卡、暂停、结算、结局、成就、广告、多人房间等场景；src/net 实现多人对战网络通信。浏览器预览目录 tools/browser-preview 为本地调试适配层，不参与微信小游戏打包。

# 10 软件技术特点

- 原生小游戏实现：使用 JavaScript 与 Canvas 2D 直接绘制全部画面，不依赖第三方游戏引擎，包体轻量、加载快，适配微信小游戏运行环境。
- 模块化与场景化架构：将认证、标题、难度、剧情、关卡、结算、结局等功能封装为独立场景，由场景管理器统一调度，代码职责清晰、易于扩展。
- 程序化美术与背景：山峦、星空、云层、侵蚀机、陨石等大量视觉元素由程序化算法实时绘制与着色，配合美术资源替换机制，兼顾表现力与资源体积。
- 面向对象实体体系：自机、敌机、子弹、BOSS、掉落物等均以实体对象建模，统一管理更新、渲染与碰撞，支持对象池与批量绘制，保障弹幕密集场景下的运行性能。
- 数据驱动关卡与难度：关卡波次、敌机编队、弹幕与 BOSS 行为通过配置数据驱动，难度参数集中管理，便于数值调整与内容扩展。
- 多人在线对战：基于 WebSocket 实现房间制对战，包含昵称、房间码、随机种子同步、时钟校准、RTT 统计与对战消息协议，支持本地与局域网联机调试。
- 完善的本地持久化：存档、实名认证、成就与解锁状态均本地持久化，结构带版本号，支持断点续玩。
- 性能优化：采用逻辑分辨率适配、渲染裁剪、粒子合并、对象复用等手段，针对移动端进行性能调优。

# 12 常见问题

- 问：游戏无法启动或黑屏怎么办？答：请确认使用微信开发者工具以“小游戏”类型导入工程，AppID 配置正确，并保持基础库为较新版本后重新编译。
- 问：如何继续上次的进度？答：在标题界面点击“继续游戏”，软件会读取本地存档并进入上次保存的关卡与难度。
- 问：如何更换难度重新开始？答：在标题界面点击“开始新游戏”并重新选择难度；如需清空存档，可在暂停界面的存档管理中选择清档退出。
- 问：为什么进入游戏前需要实名认证？答：按防沉迷与平台要求，首次进入需完成实名信息登记；本软件当前在本地完成演示校验。
- 问：多人对战无法连接怎么办？答：请确认对战服务器已启动、双方网络可达（本地或局域网），并检查服务器地址配置是否正确。
- 问：如何解锁内测跳关入口？答：在广告场景完成观看流程后即可解锁标题界面的跳关按钮，便于测试后续关卡。

# 附录E 数据存储字段说明

- 存档数据（cloudspire_save_v1）：记录难度、当前关卡、分数、生命、经验、等级、能量、剧情进度与时间戳等，用于“继续游戏”。

# 附录F 多人对战流程与协议说明

- 昵称输入：进入 PK 前先输入昵称，昵称将显示在对战界面中。
- 创建房间：房主创建房间后获得房间码，等待另一名玩家加入。
- 加入房间：另一名玩家输入房间码加入，双方建立连接。
- 开始对战：房主点击开始后，系统同步随机种子，保证双方场上事件一致。
- 对战过程：双方通过 WebSocket 实时同步对战状态，包含位置、得分、胜负判定等消息。
- 结果处理：一方达成胜利条件后广播结果，双方显示胜负并记录成就。
- 断线与超时：连接断开或超时进行提示与处理，避免界面卡死。
- 服务器地址：默认连接本地/局域网服务器，可通过界面修改服务器地址，便于不同网络环境联调。

- 经验升级：击落敌机获得经验，经验满自动升级。
- 掉落提示：拾取经验道具获得经验，拾取回复道具恢复生命。
- 生命归零：自机被击毁，本局结束。
- 继续游戏：读取最近一次存档进度。
- 清档说明：清档后本地存档、进度与设置将被清除。
- 重新挑战：从本关开头重新开始当前难度。
- 返回标题：结束当前对局并返回主菜单。
- 音频提示：首次触摸屏幕后开启声音。
- 资源加载：正在加载游戏资源，请稍候。
- 完成加载：资源加载完成，即将进入游戏。
- 防沉迷提示：请合理控制游戏时间，健康游戏。
# 附录L 软件目录与运行文件说明

- 工程根目录：包含小游戏入口 game.js、小游戏全局配置 game.json、微信开发者工具工程配置 project.config.json 与项目说明文件。
- game.js：小游戏启动入口，完成运行环境补丁与主游戏对象的创建、启动。
- game.json：小游戏配置，声明竖屏方向、状态栏与网络超时等参数。
- project.config.json：微信开发者工具工程配置，声明编译类型为小游戏、AppID、ES6 与压缩等设置。
- assets 目录：存放音频与图片资源；audio 子目录为背景音乐与音效，images 子目录为游戏图片素材。
- src/core 目录：平台适配、场景管理、输入、存储、音频、资源、粒子、成就与程序化背景等基础模块。
- src/config 目录：难度与关卡配置文件。
- src/ui 目录：菜单、HUD 与氛围特效等界面绘制模块。
- src/entities 目录：自机、子弹、敌机、BOSS 与异形母舰等游戏实体。
- src/scenes 目录：实名、加载、标题、难度、剧情、关卡、暂停、结束、结算、结局、成就、广告、多人等场景。
- src/net 目录：多人对战网络通信模块。
- src/utils 目录：数学、随机数、身份证校验与着色等工具函数。
- tools 目录：开发期辅助脚本、多人对战本地服务器与浏览器预览相关工具。
- tests 目录：自动化测试用例，用于逻辑与流程回归验证。
- 上述 tools 与 tests 目录仅用于开发调试与测试，不随微信小游戏正式包发布。
- 发布时微信开发者工具将依据工程配置忽略 tools、tests 与说明文档等非运行文件。
