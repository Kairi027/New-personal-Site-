# 参考素材清单

请把参考图放入本目录，文件名按下面命名即可：

- `player.png`：自机「飞戈-1」截击机设定图，侧俯视最好。
- `enemy_s.png`：小型敌机。
- `enemy_m.png`：中型弹幕敌机。
- `enemy_h.png`：重型轰炸机。
- `boss.png`：Boss 重轰炸机。
- `bullets.png`：弹道/弹丸参考。
- `mountain_bg.png`：黄土山峦背景参考 2-3 张。
- `title_style.png`（可选）：标题或 UI 画风参考。

如果直接提供透明背景成品 PNG，请放到 `assets/images/` 并使用同样文件名，游戏会自动加载替换程序占位。
