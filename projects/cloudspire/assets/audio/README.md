# BGM 放置说明

把音乐文件放入本目录并保持文件名一致，游戏会自动播放：

- `title.mp3`：标题界面与难度选择界面使用。
- `stage1.mp3`：Stage 1 战斗界面使用。
- `stage2.mp3`：Stage 2 雷暴云海战斗界面使用。
- `stage3.mp3`：Stage 3 云顶决战（含假结局分支）使用。
- `stage4.mp3`：Extra Stage 湮灭虚空使用。
- `boss4.m4a`：Extra Stage 终局母舰战使用。
- `he.mp3`：真结局使用。

全部 BGM 都会循环播放（首尾相接，不会只播一遍），若运行环境忽略循环标记，
游戏会在曲目结束时自动重新播放。支持微信小游戏的常见音频格式，推荐 MP3。
文件放入后刷新预览即可生效。
