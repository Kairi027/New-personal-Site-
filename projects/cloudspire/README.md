# 云阙飞戈 Lances of Cloudspire

原生微信小游戏竖版弹幕射击，复古科幻空战风格。当前版本包含完整可玩的第 1 关「黄土天穹｜钢铁机群」，以及实名认证、标题、难度选择、剧情、暂停/存档/继续、Game Over、Stage Clear 等外围系统。

## 运行方式

### 微信开发者工具
1. 在微信开发者工具中选择「小游戏」项目。
2. 导入本目录，AppID 可使用测试号，或替换 `project.config.json` 中的 `appid`。
3. 编译后即可在模拟器中运行。

### 浏览器预览
```bash
node tools/browser-preview/build.js
node tools/browser-preview/server.js
```
打开 `http://localhost:5173`。浏览器预览只用于本地调试，不参与微信小游戏打包。

## 操作
- 手指在屏幕上按住拖动移动自机，松手停止。
- 自机自动开火，击杀敌人获得经验升级。
- 左下角红球为必杀，点按释放「全域清扫」。
- 右上角为暂停按钮，暂停后可继续、存档退出或清档退出。

## 美术素材
- 当前使用程序绘制的写实风战机与黄土山峦背景占位。
- 参考图请放入 `assets/reference/`，透明背景成品 PNG 放入 `assets/images/`，文件名见该目录 README，放入后游戏会自动加载替换。

## 本地实名演示
浏览器预览中可使用任意合法格式的 18 岁测试身份证，例如：
`110105199001011232`（该号码仅用于本地逻辑校验，非真实证件）。

点击右上角「重置」可清除本机认证与存档。

## 工程结构
- `game.js` 小游戏入口
- `src/scenes/` 实名、标题、难度、剧情、关卡、暂停、结算等场景
- `src/entities/` 自机、敌机、Boss、子弹、掉落物
- `src/core/` 循环、输入、存档、音频、粒子、背景
- `src/config/` 难度与关卡配置
- `tools/browser-preview/` 浏览器预览适配层
